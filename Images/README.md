# Regal Inn image placement

Use only your own photos in `Images/Pictures/`.

The room-card mapping is in `Default.aspx.cs` (`ImageForRoomType`):
- Suite rooms: `suite twin beds1.png`
- Twin rooms: `standard 2 double beds.jpg`
- King rooms: `Standard king bed.jpg`
- Other rooms: `Regal pic 1.jpg`

Replace those files with your own photos while keeping the filenames, or change the file paths in that one method. The About-page hero uses `Images/Pictures/Regal.jpg`.
